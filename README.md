# PC Toolbox v1.0

My first completed Python project.

This application displays useful Windows system information from a simple command-line menu.

## Features

- Computer Information
- Network Information
- Disk Information
- Running Processes

## Requirements

- Python 3.12+
- psutil

## Installation

pip install -r requirements.txt

## Running

python pc_toolbox.py

## Future Features

- CPU Usage
- Memory Usage
- Network Statistics
- Export Results
