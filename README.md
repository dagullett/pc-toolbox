## Installation

1. Clone the repository:

```bash
git clone https://github.com/<your-username>/PC-Toolbox.git
```

2. Install the required dependencies:

```bash
pip install -r requirements.txt
```

3. Run the application:

```bash
python pc_toolbox.py
```
